# Week 02 – Stakeholder Requirement Analysis

## Project
**GlobalCart – E-Commerce Order Management System Improvement**

## Folder Contents

This folder contains the following deliverables:

1. **Stakeholder Requirements Report** – Documents the business scenario, stakeholder analysis, simulated interviews, business requirements, functional and non-functional requirements, and proposed improvements.
2. **AS-IS Process Diagram** – Shows the existing order management process, including manual stock checking and customer communication.
3. **TO-BE Process Diagram** – Shows the proposed improved process with automatic stock checking, inventory updates, website stock updates, and customer notifications.

## Tools Used
- Microsoft Word
- Draw.io (diagrams.net)
- BPMN 2.0

## Note
GlobalCart is a fictional company, and the stakeholder interviews and responses are simulated for this internship task.

## Objective
To understand stakeholder needs, analyse an existing business process, document system requirements, and propose improvements to the order management process.
